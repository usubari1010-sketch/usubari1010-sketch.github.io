プライバシーポリシー

本ポリシーは、YouTubeチャンネル「うちまき」の動画を制作するために、 運営者本人だけが使う非公開ツール(以下「本ツール」)についてのものです。 本ツールは一般に配布しておらず、運営者本人の Google アカウント以外からは利用できません。

1. 取得する情報

本ツールは、運営者本人が許可した場合にかぎり、YouTube Data API および YouTube Analytics API を通じて次の情報を取り扱います。

権限用途
youtube.upload運営者自身のチャンネルへ動画を投稿する
youtube.readonly投稿済み動画の題名・公開状態・サムネイルを確認する
youtube.force-ssl自チャンネルのコメントを読み、返信する
yt-analytics.readonly自チャンネルの再生数・視聴維持率を確認する

2. 情報の保存場所

取得した情報と認証トークンは、運営者個人のパソコン内にのみ保存します。 外部のサーバーへ送信・保管することはありません。第三者へ提供・販売することもありません。

3. 情報の利用目的

自チャンネルの動画の制作・投稿・改善、および視聴者コメントへの返信のためだけに使います。 広告配信や分析のための第三者提供は行いません。

4. 利用者

本ツールの利用者は運営者本人のみです。第三者のアカウント情報を取得することはありません。

5. 連絡先

お問い合わせ: YouTubeチャンネル「うちまき」(@u_sbari)のコメント欄、 または Google アカウントに登録のサポート用メールアドレス宛にご連絡ください。

6. 改定

内容を変更した場合は、本ページを更新します。
